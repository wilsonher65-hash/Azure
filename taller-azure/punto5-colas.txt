El almacenamiento de colas (Azure Queue Storage) es un servicio de Microsoft Azure que permite guardar una gran cantidad de mensajes en la nube para procesarlos después. Se accede a ellos mediante llamadas autenticadas por HTTP o HTTPS. Cada mensaje puede pesar hasta 64 KB y una cola puede contener millones de mensajes, hasta el límite de capacidad de la cuenta de almacenamiento. Por defecto, un mensaje dura 7 días, aunque ese tiempo se puede cambiar.

Funciona con un productor, que envía mensajes a la cola, y un consumidor, que los lee, los procesa y luego los elimina. Al leerse, el mensaje queda oculto por un tiempo; si el consumidor falla y no lo elimina, vuelve a aparecer para que se procese de nuevo. Los mensajes suelen atenderse en orden de llegada, pero ese orden no está garantizado.

Se utiliza para comunicar partes de una aplicación de forma asíncrona, sin que dependan directamente entre sí; para ejecutar tareas en segundo plano, como enviar correos o procesar imágenes y videos; y para manejar picos de trabajo sin saturar el sistema. Por ejemplo, en una alarma de incendios, un ESP32 puede enviar las lecturas de sus sensores a una cola y un programa las procesa una por una para calcular el nivel de riesgo.
